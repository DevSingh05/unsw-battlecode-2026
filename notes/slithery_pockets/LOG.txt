2. Implementation (bot/main.cpp + params.hpp, DIVE_VALUE=0 default; flags-off verified byte-identical replay on
   slithery seed 5 vs the pre-change binary)
   dvNet(P, turns) = P - 2 - DV_TURN_COST*turns if the tip split is possible (L+P>=4 and a unit slot), else -L.
   P = best single inward path (pfBranch for static pockets; dvRegionPath DFS for body-made dead ends), times
   dvContest (1 - DV_CONTEST per enemy head within 3 of the mouth).
   DV_PARTS bits: 1 pfDiveOK gate (V>=DV_MARGIN), 2 old pump gate (pocketWorthPumping: path P instead of summed
   pearls), 4 inward-born child (pfChildInwardBad), 8 scoring: non-approved static-pocket entry pays
   DV_PEN*(DV_MARGIN-V). DV_FUNNEL (off): same rule one step early - a core tile whose single core exit another head
   within 2 can take, with only losing pocket entries otherwise, pays DV_FUNNEL*DV_PEN*(DV_MARGIN-Vf).
