## Changes since old rules (01-game-rules.md, written 2026-09-26)
1. **Queens.** Dragons id 0 and id 1 are the queens (map-file DRAGON lines alternate teams, so 0 and 1 are always on different teams; id 0 = team A, moves first each round). After round 500 the winner is: (1) longer queen, dead queen = length 0; (2) longest living dragon; (3) greatest total length; (4) draw. Old rule had no queen step. Queen death does NOT end the game; elimination (all dragons dead) still wins outright, both eliminated same round = draw.
2. **Free sprint steps.** First ceil(L/4) steps of a turn are free, L = length at the start of the move (old: 1 free step). Each later step removes one extra tail segment and needs length >= 3 before paying (length 2 cannot pay -> No Valid Action death). Max steps with no pearls = ceil(L/4) + (L-2). Cost of x steps = max(0, x - ceil(L/4)). Docs examples: 5 steps cost L=4 four segments (fatal), L=12 two.
3. **Pearls during sprints.** Free step onto a pearl: tail stays, +1. Paid step onto a pearl: tail stays then one segment removed, net 0. Collision and eating checked at every step; step k is checked against the body as step k-1 left it. Death on any step discards remaining steps and the turn's sonar; steps taken stand.
4. **Elo replaced** (see Ladder). All ratings reset to 1500 at 2026-10-01 09:00 UTC; new Bayesian per-map rating per *submission*. All submissions were marked idle at the update and had to be re-activated.
5. **Continuous autoscrims** now on (site sidebar "Autoscrims: Continuous"; update post: about 3 matches per team per hour).
6. **Team lock:** cannot leave a team you have been in for more than 7 days (effective immediately).
7. **New maps coming** "over the next several days" across CLI/site/repo: similar geometry, queens spawn in much safer, more consistent spots. Not in 1.2.3 yet (bundled maps identical to ours except trailing-newline diffs in portals/slithery_fight).
8. Pearl spawn schedules are seeded randomly per match (since 1.1.0, 25 Sep); replays carry the seed; `unswbc run --seed`.
9. Scrim team order (A/B) is shuffled (28 Sep). Moving first is worth +20 Elo in the prediction model.

## Full current rules (unchanged unless noted)
- Map 10..64 per side, torus wrap, symmetric (mirror x, mirror y, or 180 rotation). Edges: open / kelp (wall, death "Hit Wall") / portal (paired id, same orientation, direction preserved, sonar passes, vision does not).
- Start: per map, 2-14 dragons total, lengths 3-14 (helper says "length 3 at spawn" but maps differ). Unit cap 64 living per team (UNIT_LIMIT). Min length 2.
- Rounds: max 500. Round = pearl tick (every tile countdown -1, row-major; at 0 spawn if tile empty, redraw U[min_gap,max_gap] either way; mirrored tiles share countdown; max_gap 0 => -1, never) then each dragon in ascending id; split children appended, act later the same round.
- Turn: inbox+echoes delivered, default action = suicide, read until ENDTURN, apply action, cast sonar if alive. MOVE/SPLIT overwrite each other; last wins.
- Collisions: own body (incl. tail, checked before tail moves) then others; other head => both die (victim's death sequence first); other body => mover dies. Backward move into neck is fatal.
- Split: child = rear k segments reversed (old tail = child head, faces away), k >= 2, parent keeps >= 2, team < 64 alive; illegal split kills parent. One action per turn (no move+split).
- Death drops ceil(L/2) pearls on every second segment starting at the head; countdowns unchanged.
- Vision: 7x7 Chebyshev 3 around head, wraps, not through portals. Per tile: coords, pearl, countdown, dragon part (team, id, head, dir), 4 edges.
- Sonar (protocol 3): up to 4 per turn (one per N/E/S/W), uint64 each, cast after action in N,E,S,W order from the head; a ray opposite the facing exits from the tail along the tail's outward direction. Stops at first kelp or dragon part (any team, incl. self), lost after W+H tiles. Read next turn (higher id same round, lower id next round). No sender info. Echo counts (kelp, ally body, ally head, enemy body, enemy head), aggregated over rays.
- Compute (judge): 100M CPU points per dragon per turn, 48 MB, 1 thread; backstop 1 s CPU / 10 s wall. First turn not exempt. stdout write = 2.5M + 4000/byte. Python parse ~10M/round. Logs capped 500k lines / 16 MB per team per game, indicator 512 chars. Local `unswbc run` has only a 10 s wall clock; use `--sandbox -v` to see points. C/C++: clang 20, -O2 -msimd128, C17/C++20, wasi. Python 3.13 + NumPy 2.5.3. Deterministic per seed.
- Overview still says "approximately 25 ms" per turn; superseded by the points meter.

## Ladder & Elo (docs /elo, /game-format)
- Each submission has overall rating R and per-map offset O_m, each a mean +- sigma. Team rating = active submission's R + mean of O_m over the ranked map pool, rounded, floor 0. Tiers: Plankton <700, Shrimp 700, Tunafish 1100, Swordfish 1500, Shark 1900, Orca 2300, Leviathan 2700, Fishing Boat 3000+.
- Predict: c = ln10/400; z = c(RA+OA,m-RB-OB,m+20 [first mover]); v = c^2 * sum of four sigma^2; s = sqrt(1+pi v/8); p = 1/(1+e^(-z/s)). Update (Kalman step): mean += sigma^2 c (y-p)/(s(1+hv)), sigma^2 -= sigma^4 c^2 h/(1+hv), h = p(1-p)/s^2.
- Priors: team's first submission 1500+-200 overall; unseen map offset 0+-150. New upload inherits the previous active submission's numbers with extra +-75 (moves fast at first). Re-uploading identical code (same file contents; zip metadata, __MACOSX, .DS_Store, __pycache__ ignored; any change, even a comment, = new code) restores that code's exact rating. Re-activating an old submission restores its rating. Switching active submission moves team rating immediately.
- Team rating on the ladder updates once per ranked battle (5 games); bot rating per game. Unranked games do nothing. Model log loss 0.5705 (69.6% winner called) vs old 0.6716.
- Ranked battle = 5 games, random maps from the ranked pool. Unranked: pick maps, 1 game per map. All battles public.
- Manual challenges: 60 games/hour by hand (= 12 ranked scrims), plus a separate 60 games/hour vs DEV teams. Ranked requests need the ranked switch on for both teams and the target rated no more than 50 below you (anyone above is fine). The switch has an 8-hour cooldown between flips (ours last flipped 2026-10-01 14:03:51 UTC).
- Autoscrims (ranked, don't use the allowance, need only an active submission). Hourly mode: each UTC hour, one opponent from 8 places above/below. Continuous mode (on now): fixed-rate queue, whoever had fewest in last 24 h drawn next, opponents up to 50 places either side, weighted to close games and teams not met recently, one autoscrim at a time.
- Submissions: zip <= 4 MB, 12 uploads per hour (site and API), unlimited activations, cannot be deleted. API: 120 req/min per key, 30/min for /leaderboard and /ratings.
- Current ladder (15:40 UTC): #1 Cache me outside 2091, Sponge 1986, Stockfish 1986, calc 1981 (ineligible), 3.14159265 1972, 963 teams.
