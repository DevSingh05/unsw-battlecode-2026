# v69 = v61 + QEARLY_PEN (early queen gets the portal/blind-tile penalties), 2026-10-04

Fix 3a of notes/newrules/LOSS_AUDIT2.md. Directory variants/v69 (cp of v61). Nothing submitted, no challenges.
With `-DQEARLY_PEN=0` v69 = v61 (QEARLY_ENCL defaults to 0).

## What changed
Before QS_FROM (r100) the queen plays the early economy (`queenEarly()`), and `queenSafe()` is false, so she had no
portal penalties. That is how she reached kelp pockets / 2x2 portal vaults on Portals, Australia and Around UNSW and
died in QBOX_K2 shed chains. v69 adds one helper and uses it in three places:

```cpp
bool qPortalPen() const { return queenSafe() || (QEARLY_PEN && queenEarly()); }
```
- `QUEEN_PEXIT_PEN` (80) on portal-exit tiles: `queenSafe()` -> `qPortalPen()` (main.cpp ~5340)
- `QUEEN_BLIND_PEN` (200) for a portal crossing onto an unseen tile: `queenSafe()` -> `qPortalPen()` (~5341)
- fast-step candidate veto when the landing has blind 2nd-ring tiles: `queenSafe()` -> `qPortalPen()` (~4568)

Nothing else from queen-safe mode moves earlier: kingship, feeding, splitting, threat model, QUEEN_LOOK etc. still wait
for QS_FROM. Not a rerun of QEXIT_LOOK (no lookahead; just the existing static penalties).

Optional, off by default: `QEARLY_ENCL` (a QUEEN_ENCLOSE_PEN-style open-area penalty for the early queen, one BFS per
candidate). Tested at 400, no mechanism gain over plain v69, so it stays 0.

params.hpp (end): `QEARLY_PEN 1`, `QEARLY_ENCL 0.0`.

## Checks (local, vs v61, both sides)
- Compiles clean (same warnings as v61). Smoke/mechanism games had no errors.
- Sandbox seed 1000 vs v61 (main.cpp touched first): Australia max 32.6M (p99 30.4M), Schooltime max 27.1M (p99 24.5M).
  Under 40M.
- Mechanism (scratchpad mechq.py, cause "trapsplit" = queen split within 4 rounds before dying at L<=3, the audit's
  definition). Maps: portals, sprint/australia, sprint/around_unsw, slithery_fight, 4 seeds x 2 sides (seed 691000),
  plus portals + australia, 4 seeds x 2 sides (seed 692000). 48 games.

| | v69 | v61 |
|---|---|---|
| queen alive at r100 | .65 | .25 |
| queen deaths before r100 | **17 / 48** | 36 / 48 |
| of which trapsplit | **5** | 24 |
| of which head-on | 9 | 8 |
| median queen death round | ~165 | ~53 |
| queen deaths after r100 | 29 | 10 |
| queen alive at r500 | .04 | .04 |

  Pre-r100 by map (batch 1, 8 games each): Portals 4 v 8, Australia 3 v 7, Around UNSW 4 v 3, Slithery 0 v 4.
- The target pattern drops sharply (pre-r100 trapsplits 24 -> 5). But in self-play the queen still dies later
  (post-r100 trapsplits 13 v 4 in batch 1) and r500 queen survival is unchanged. So locally it delays the death rather
  than prevents it.
- Win rate (sanity only): batch 1 17/32 (AUNSW 6/8, Slithery 5/8, Portals 3/8, Australia 3/8); batch 2 5/16
  (Portals 2/8, Australia 3/8). Total 22/48. With QEARLY_ENCL=400: 14/32 + 11/16 = 25/48, same queen numbers.
  Both are inside noise.
