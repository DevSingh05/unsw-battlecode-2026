# v37b: PLAN.md steps 2 (QGUARD), 5 (ONEKING), 6 (CASCADE), 2026-10-01
Base: copy of variants/v36. Engine unswbc 1.2.3. Each step sits behind its own flag in params.hpp, default 0.
Per-flag tests used QUEEN_SAFE=0 FREE_FIX=0 THREAT_FREE=0 QUEEN_HUNT=1 (LOOK/ENCLOSE/DIST_VETO/KING=0).
After v36 went live, the defaults were reset to v36's values (QUEEN_SAFE/FREE_FIX/THREAT_FREE/QUEEN_HUNT=1), so params.hpp now equals v36 plus the three new flags at 0.

## Implementation (main.cpp, located by code)
- Helpers next to amQueen(): kReach(L)=ceil(L/4)+L-2, qGuard(), qgCap(k), oneKing()/noVolSplit().
- QGUARD (QG_FROM 20 / QG_UNITS 5, QG_MIN 5): normal split, PF early split, PF split, keepLen SPLIT 2 and echo-hold SPLIT 2 are capped at k<=L-5, with no split if k<2.
  King-escape reverse split is blocked for the queen. The trapped reverse split happens for the queen only when bestD<0. Pocket pump and pfIn are off for the queen.
  Dead-end veto: for a candidate with area < L+3, switch to the best open alternative with depth >= QUEEN_VETO_DEPTH that is not a QUEEN_SAFE-threatened tile, so the veto can never undo the QUEEN_SAFE veto.
  Allies get -QG_ALLY_PEN(300) for ending within min(K(myLen), QG_ALLY_KCAP=3) of our visible queen head. The cap is a deviation from PLAN: an uncapped K covers the whole view.
  Not done: the "unless she can reverse out" clause. The queen keeps the head piece, so a reverse split never gets her out.
- ONEKING (OK_FROM 200): leader = myLen >= kingLen and >= OK_MINLEN(5). OK_MINLEN is added because kingLen=0 when no beacon is heard. The leader makes no voluntary split
  (normal, keepLen, echo-hold, PF, king-escape). The trapped split is unchanged.
- CASCADE (CC_ROUNDS 3, CC_MINLEN 6): in the split block k=L-2 (queen L-3 when QGUARD is compiled in) if no visible enemy head is within K(max(3,visLen))+2 and tailHasExit(k).
  On dilemma the enemy queen (L12, K=13) is always within K+2, so it never fires there.
