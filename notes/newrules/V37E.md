# v37e: v37d + QGUARD (PLAN.md step 2, ported from v37b), 2026-10-01
Base: copy of variants/v37d (QKILL=1, KREACH_KING=1, THREAT_FREE=0). v37d is unchanged. Only QGUARD was ported; ONEKING and CASCADE were not.

## Code (variants/v37e)
- params.hpp, new block at the end: QGUARD 1, QG_FROM 20, QG_UNITS 4 (v37b used 5; AB_DIAG asks for >= 4 units), QG_MIN 5, QG_ALLY_PEN 300, QG_ALLY_KCAP 3. QGUARD=0 gives v37d.
- main.cpp: the v37b hunks were applied as a unified diff. The only conflict was the helper block, which now sits after queenEarly(): kReach, qGuard, qgCap.
  noVolSplit() is a stub that returns false (ONEKING not ported), and the CASCADE block was removed.
- Split caps: every voluntary split (normal, tip, SPLIT_VIABLE, PF early, PF, keepLen SPLIT 2, echo-hold SPLIT 2) is limited to k <= L-5, with no split if k < 2. King-escape split, pfIn and pocket pump are off for the queen.
  The trapped reverse split fires only when bestD < 0, meaning every move is lethal.
- Dead-end veto runs after v37d's QUEEN_SAFE threat veto and dist veto. Its alternative must have candThreat == 0 whenever queenSafe() (QS_FROM 0, so always), so it never undoes the threat veto.
- Allies take -300 for ending a step within min(K(myLen),3) of our queen's visible head.
